1. Fitur Responsif
   
Website yang saya deploy sudah memiliki 3 fitur responsif untuk mobile, tablet dan desktop. ukuran website di layar bisa berubah sesuai dengan resolusi perangkat pengguna entah device mana yang mereka gunakan. untuk mobile, navbar akan berubah menjadi *hamburger menu* interaktif. layout juga diubah menjadi vertikal. Sedangkan untuk tablet layout diubah menjadi grid 2 kolom. Sedangkan untuk desktop layout penuh dengan navigasi horizontal.

2. HTML, CSS dan Javascript (DOM)

HTML       : HTML digunakan untuk struktur semantik dasar website.
CSS        : Styling yang saya pakai di sini sudah murni dari CSS. Yang digunakan antara lain Variables, Flexbox, Grid dan queries.
JS (DOM)   : - Digunakan untuk hamburger menu di layout mobile
             - Digunakan untuk menyapa user berdasarkan jam lokal user
             - Menunjukkan tahun copyright di footer website.
